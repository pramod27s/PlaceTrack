# PlaceTrack — Features

**PlaceTrack features in short:**

1. **Company Pipeline** — Kanban board to drag companies through stages (Applied → OA → GD → Tech → HR → Offer/Rejected). Each company card also has a `Registered on Superset` checkbox so you can quickly see which companies you've completed the TPO-portal registration step for (eligibility & deadlines themselves are owned by Superset).
2. **Round Scheduler** — Add date, time, mode, and meeting link for each interview round
3. **Smart Notifications** — Browser push + email + in-app bell at 24h / 1h / 15min before rounds, plus daily morning digest
4. **Conflict Detection** — Auto-warns when two rounds overlap
5. **Interview Journal** — Log questions asked and reflections after each round to build a personal prep dataset
6. **Resume Vault** — Upload multiple resume versions and track which one went to which company
7. **Offer Comparison** — Side-by-side compare of CTC, role, location, and bond when multiple offers arrive
8. **Analytics Dashboard** — Stage-wise drop-off, conversion rates, and where you're losing
9. **Auth** — Email + Google login, with per-user private data
10. **Company Research Notes** — Per-company notes section to capture culture, tech stack, recent news, interviewer names, and "why I want to work here" — keeps all your research in the same place as the application itself
